# Spot Analyzer Bot 🤖

ربات تلگرامی تحلیل‌گر اسپات که برای هر ارز درخواستی، به‌صورت خودکار:
- داده قیمتی را از صرافی بایننس دریافت می‌کند
- حمایت/مقاومت، خط روند، سطح شکست، RSI و حجم را محاسبه می‌کند
- Entry / Stop Loss / Take Profit و نسبت ریسک به ریوارد را می‌سازد
- امتیاز چند تایم‌فریم (15m, 30m, 4h, 1d) و فیلتر بازار بر اساس BTC را محاسبه می‌کند
- یک چارت annotate‌شده (شبیه تصویر نمونه) + خلاصه متنی فارسی ارسال می‌کند

## نصب

```bash
pip install -r requirements.txt
```

## تنظیم توکن ربات

توکن را از @BotFather در تلگرام بگیرید، سپس یکی از دو روش را انجام دهید:

**روش ۱ - متغیر محیطی (پیشنهادی):**
```bash
export TELEGRAM_BOT_TOKEN="123456:ABC-your-token-here"
```

**روش ۲ - مستقیم در فایل `config.py`:**
```python
BOT_TOKEN = "123456:ABC-your-token-here"
```

## اجرا

```bash
python bot.py
```

## نحوه استفاده در تلگرام

1. `/start` را بفرستید تا منوی اصلی نمایش داده شود.
2. روی «🔍 تحلیل ارز» بزنید.
3. نام ارز را وارد کنید (مثلاً `BTC` یا `RESOLV`).
4. سرمایه خود را به دلار وارد کنید (مثلاً `3000`).
5. قیمت ورود (Entry) مورد نظر را وارد کنید (مثلاً `0.01687`).
6. ربات چارت + تحلیل کامل را ارسال می‌کند.

سایر دکمه‌های منو (تحلیل مجدد، سود و ضرر، تغییر Entry، SL/TP، راهنما) روی
آخرین تحلیل انجام‌شده عمل می‌کنند.

## ساختار فایل‌ها

| فایل | وظیفه |
|---|---|
| `config.py` | تنظیمات و توکن |
| `data_fetcher.py` | دریافت کندل از صرافی (ccxt) |
| `indicators.py` | RSI، حجم، سوینگ‌ها، خط روند، حمایت/مقاومت |
| `analysis.py` | موتور تحلیل: Entry/SL/TP، امتیاز تایم‌فریم‌ها، فیلتر BTC |
| `chart.py` | تولید تصویر چارت annotate‌شده |
| `messages.py` | ساخت متن فارسی خروجی |
| `bot.py` | هندلرهای تلگرام و منطق مکالمه |

## نکات مهم

- منبع داده پیش‌فرض بایننس است (از طریق ccxt)؛ اگر صرافی دیگری می‌خواهید،
  مقدار `EXCHANGE_ID` را در `config.py` تغییر دهید (مثلاً `"kucoin"`).
- محاسبات حمایت/مقاومت و امتیازدهی تایم‌فریم‌ها بر پایه قواعد تکنیکال ساده
  (سوینگ‌پوینت‌ها، EMA20/50، RSI، حجم) هستند و **توصیه مالی نیستند** —
  قبل از هر معامله واقعی، تحلیل خودتان را هم انجام دهید.
- اجرای پایدار روی سرور نیاز به یک پروسه همیشه-روشن دارد (مثلاً با
  `systemd`، `pm2`، یا `screen`/`tmux`، یا هاست‌های ابری مثل Railway/Render).
